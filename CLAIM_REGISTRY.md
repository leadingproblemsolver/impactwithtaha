# Claim Registry — Public Safe Boundary

## Global rules
- AI assistance is explicit; do not imply unaided authorship where implementation was materially AI-assisted.
- Separate repository contents from independently demonstrated competence.
- Offline tests prove deterministic/local contracts only.
- Deployment readiness is not production verification.
- Architecture is not user value.
- Outreach/distribution infrastructure is not revenue, adoption, meetings, or pipeline.
- Personalization changes relevance and presentation, **not proof level**.
- No invented performance, adoption, client, hiring, conversion, revenue, ROI, or prevented-incident metrics.

## Proof ladder
- **P1 — Artifact:** something exists.
- **P2 — Reproducible:** behavior can be inspected/reproduced.
- **P3 — Deployed:** usable external surface exists.
- **P4 — External interaction:** real market/user/maintainer interaction occurred.
- **P5 — Measured outcome:** user/system behavior changed with evidence.
- **P6 — Economic outcome:** attributable revenue/pipeline/cost/time outcome.

Never collapse these states.
