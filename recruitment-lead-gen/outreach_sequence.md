# 3-Touch Outreach Sequence

## Constraint

The sequence is designed to test **relevance**, not manufacture urgency.

- one source-backed trigger;
- one narrow problem hypothesis;
- one CTA;
- no invented pain;
- no claim that the target already uses agencies;
- no meeting request before relevance is established.

## Touch 1 — Email, Day 0

**Subject:** `[Company] — selective search capacity?`

`Hi [First name] — I noticed [source-backed hiring/growth trigger]. When internal TA is carrying several role families at once, external support is usually most useful only on the roles that stay hard to fill. We can add focused sourcing, qualification and warm handoff for an agreed role/location without changing your internal process. Is there one role or location where selective recruitment support would be useful this quarter?`

## Touch 2 — LinkedIn, Day 2

`Hi [First name] — I sent a short note after seeing [same supported trigger]. Not looking to replace internal TA; the question is whether one hard-to-fill role/location would benefit from extra specialist search capacity. Worth keeping us as an overflow option?`

## Touch 3 — Email close-loop, Day 5

`Hi [First name] — closing the loop on my note about [Company]. If there is no external-recruitment need, I’ll step back. If one role is stubborn, send the title + location and we can return a small target-market view before discussing anything broader.`

## Measurement

The sequence is evaluated on:
- substantive reply;
- explicit no / objection;
- qualified discovery intent;
- calendar/meeting receipt.

Opens are not treated as the primary outcome.
