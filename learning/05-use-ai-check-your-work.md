# Use AI, Check Your Work

**A free REF learning mini-workbook | October 2026 | Reader edition 1.0**
**Audience:** Teenagers and first-time AI users, 14+
**Learning outcome:** Ask for help while preserving independent verification and privacy.

## How to use this book
Read the short explanation, attempt its practice before checking the worked answer, then change the example and repeat from memory.

## 1. Define the output and check

“Make this amazing” is vague. State audience, constraints, sample input, expected result and how to judge success.

**Your practice:** Rewrite “Do my science project” as a learning request.

**Worked example / answer check:** Ask for three safe project options, what each tests and a checklist to run one yourself.

**Transfer:** Try a new case from a different topic, without copying the example; write down what you checked.

## 2. Verify plausible claims

Fluent answers may contain errors, invented citations or outdated steps. Find trustworthy original sources for important facts.

**Your practice:** AI claims a university proved a method doubles scores. What must you check?

**Worked example / answer check:** Locate the actual study, methods, participants and outcomes; do not repeat an unverified claim.

**Transfer:** Try a new case from a different topic, without copying the example; write down what you checked.

## 3. Protect private information

Never share passwords, customer data or another person's sensitive details in a prompt without proper authorization.

**Your practice:** Rephrase a request containing a classmate's private details.

**Worked example / answer check:** Use an anonymous fictional classmate and generic circumstances.

**Transfer:** Try a new case from a different topic, without copying the example; write down what you checked.

## 4. Reconstruct independently

Explain inputs, transformations and outputs after receiving assistance. A generated answer is not yet a demonstrated skill.

**Your practice:** AI gives a formula for a spreadsheet. Name two checks.

**Worked example / answer check:** Calculate two sample rows manually; inspect empty inputs and cell references.

**Transfer:** Try a new case from a different topic, without copying the example; write down what you checked.

## Independent challenge
Ask AI for one low-stakes method, independently verify a key fact, test an edge case and document what you checked.

Use this evidence card: **before / action / expected / observed / one limitation / next test**.

## Five-day practice
- Day 1: Try lesson one before reading its example answer.
- Day 2: Recall the core idea with notes closed; check and correct.
- Day 3: Try another lesson with a changed example.
- Day 4: Complete the independent challenge.
- Day 5: Show the result to a suitable reviewer and revise one step based on real feedback.
