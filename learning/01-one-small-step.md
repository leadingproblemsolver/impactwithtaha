# One Small Step

**A free REF learning mini-workbook | October 2026 | Reader edition 1.0**
**Audience:** Young learners, 9–12 (with adult or teacher guidance)
**Learning outcome:** Turn a large goal into one safe five-minute action and visible check.

## How to use this book
Read the short explanation, attempt its practice before checking the worked answer, then change the example and repeat from memory.

## 1. A goal is not an instruction

“Do better in school” is a goal, not the next action. Describe something you can physically start and a result you can see.

**Your practice:** Turn “organise my room” into a single action and completion check.

**Worked example / answer check:** Move the five books on the desk to one shelf; confirm no books remain on the desk.

**Transfer:** Try a new case from a different topic, without copying the example; write down what you checked.

## 2. Check your starting materials

Before beginning, check that you have the needed instructions, materials and enough time. A quick check can prevent a blocked task; endless preparation will not complete it.

**Your practice:** You have a pencil but not the assignment sheet. What do you do?

**Worked example / answer check:** Request the correct task instructions, then review one known example while waiting.

**Transfer:** Try a new case from a different topic, without copying the example; write down what you checked.

## 3. Take a five-minute attempt

Start with a small, safe action. At the end, record what changed. An unsuccessful attempt can reveal exactly what needs adjusting.

**Your practice:** Write START, FINISH, CHECK and NEXT for a real school task.

**Worked example / answer check:** Start: open science notes. Finish: label three plant parts. Check: compare with a diagram. Next: explain one part.

**Transfer:** Try a new case from a different topic, without copying the example; write down what you checked.

## 4. Prove you understand

Copying an example is not the same as independently solving a different one. Change the situation, try again and compare with a correct reference.

**Your practice:** You copied a labelled plant. How do you test independent understanding?

**Worked example / answer check:** Label a different plant diagram with notes hidden, then check your work.

**Transfer:** Try a new case from a different topic, without copying the example; write down what you checked.

## Independent challenge
Choose a postponed task. Complete five minutes of actual work, preserve the result and write one honest next step.

Use this evidence card: **before / action / expected / observed / one limitation / next test**.

## Five-day practice
- Day 1: Try lesson one before reading its example answer.
- Day 2: Recall the core idea with notes closed; check and correct.
- Day 3: Try another lesson with a changed example.
- Day 4: Complete the independent challenge.
- Day 5: Show the result to a suitable reviewer and revise one step based on real feedback.
