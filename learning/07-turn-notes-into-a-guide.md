# Turn Notes into a Useful Guide

**A free REF learning mini-workbook | October 2026 | Reader edition 1.0**
**Audience:** Student writers, educators and creators, 15+
**Learning outcome:** Convert raw notes into one safe, teachable resource with an independent task.

## How to use this book
Read the short explanation, attempt its practice before checking the worked answer, then change the example and repeat from memory.

## 1. Treat the source as material

Chats and notes often mix duplicate ideas, drafts, mistakes and private information. Extract a lesson; do not publish a raw transcript.

**Your practice:** Find one learning objective in notes about missed deadlines.

**Worked example / answer check:** A learner can check the date of one deadline against the official timetable.

**Transfer:** Try a new case from a different topic, without copying the example; write down what you checked.

## 2. Choose one reader

Use examples and vocabulary that match the target learner. Define specialist terms rather than assuming expertise.

**Your practice:** Translate “idempotent processing” for a younger learner.

**Worked example / answer check:** Submitting twice should not create two identical records; show an illustrated pair of cases.

**Transfer:** Try a new case from a different topic, without copying the example; write down what you checked.

## 3. Build practice and feedback

Pair every explanation with one worked example, a learner exercise, an example answer and an independent variation.

**Your practice:** Make a source-checking transfer question.

**Worked example / answer check:** A forwarded screenshot claims the schedule changed; how do you verify the official source?

**Transfer:** Try a new case from a different topic, without copying the example; write down what you checked.

## 4. Publish with limitations

A public file proves posting, not learning. Check permissions and citations, then request one concrete exercise attempt.

**Your practice:** Write a transparent release statement.

**Worked example / answer check:** “This is a first educational edition; learning outcomes have not been evaluated. Please identify one unclear exercise.”

**Transfer:** Try a new case from a different topic, without copying the example; write down what you checked.

## Independent challenge
Make a two-page lesson from one source note with learner goal, worked example, transfer task, answer, provenance and feedback question.

Use this evidence card: **before / action / expected / observed / one limitation / next test**.

## Five-day practice
- Day 1: Try lesson one before reading its example answer.
- Day 2: Recall the core idea with notes closed; check and correct.
- Day 3: Try another lesson with a changed example.
- Day 4: Complete the independent challenge.
- Day 5: Show the result to a suitable reviewer and revise one step based on real feedback.
