# Finish a Stuck Project

**A free REF learning mini-workbook | October 2026 | Reader edition 1.0**
**Audience:** Older students and independent builders, 15+
**Learning outcome:** Recover the latest real project state and complete one bounded next action.

## How to use this book
Read the short explanation, attempt its practice before checking the worked answer, then change the example and repeat from memory.

## 1. Inspect the last observed state

Old plans are not proof. Look for the most recent file, tested result, submitted form or verified receipt.

**Your practice:** Your folder has FINAL, FINAL2 and v3. What is authoritative?

**Worked example / answer check:** Inspect content, modification history and actual use; do not assume the filename identifies the correct version.

**Transfer:** Try a new case from a different topic, without copying the example; write down what you checked.

## 2. Choose a truthful status

ACTIVE has a next action; WAIT depends on someone else; HOLD is lower priority; KILL has no justified continuation. Preserve records before retiring.

**Your practice:** Classify an application deadline, an unanswered tutor message and a redundant outline.

**Worked example / answer check:** ACTIVE; WAIT; retire duplicate after preserving any unique content.

**Transfer:** Try a new case from a different topic, without copying the example; write down what you checked.

## 3. Make one external move

Replacing a project with a bigger planning system rarely verifies the original output. Pick the smallest test, delivery or review.

**Your practice:** Turn “finish my website” into one inspectable step.

**Worked example / answer check:** Publish or preview one working page, test the links and request feedback from a specific reviewer.

**Transfer:** Try a new case from a different topic, without copying the example; write down what you checked.

## 4. Settle the evidence

Record BEFORE, ACTION, AFTER, RECEIPT and NEXT. Preparing something is not the same as sending it.

**Your practice:** Show how to close a review request.

**Worked example / answer check:** Before: draft. Action: sent for review. After: reviewer can access it. Receipt: sent message or URL. Next: wait for one named correction.

**Transfer:** Try a new case from a different topic, without copying the example; write down what you checked.

## Independent challenge
Take a genuinely stalled project, classify it, complete one action and record the real state change.

Use this evidence card: **before / action / expected / observed / one limitation / next test**.

## Five-day practice
- Day 1: Try lesson one before reading its example answer.
- Day 2: Recall the core idea with notes closed; check and correct.
- Day 3: Try another lesson with a changed example.
- Day 4: Complete the independent challenge.
- Day 5: Show the result to a suitable reviewer and revise one step based on real feedback.
