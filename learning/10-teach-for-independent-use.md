# Teach for Independent Use

**A free REF learning mini-workbook | October 2026 | Reader edition 1.0**
**Audience:** Peer tutors, teachers, mentors and educational creators
**Learning outcome:** Design a brief lesson that ends with an unaided transfer task.

## How to use this book
Read the short explanation, attempt its practice before checking the worked answer, then change the example and repeat from memory.

## 1. Make the objective observable

“Understand workflows” is not a test. Specify what learners should actually draw, explain, identify or solve.

**Your practice:** Rewrite a ten-minute goal about checking online claims.

**Worked example / answer check:** Given one claim, the learner locates an original source and names one uncertainty.

**Transfer:** Try a new case from a different topic, without copying the example; write down what you checked.

## 2. Show, assist, then fade

Demonstrate one worked example, support a similar attempt, then remove the cues for a different case.

**Your practice:** Plan “I do, we do, you do” for testing an online form.

**Worked example / answer check:** I do: valid input. We do: predict blank input. You do: independently test a duplicate.

**Transfer:** Try a new case from a different topic, without copying the example; write down what you checked.

## 3. Diagnose the specific error

Ask why the learner made a choice. A lucky correct answer does not prove the method is reliable.

**Your practice:** A student says “it worked once, so it always works.” What do you ask?

**Worked example / answer check:** “Which other input might change the result, and what would you predict?”

**Transfer:** Try a new case from a different topic, without copying the example; write down what you checked.

## 4. Use learner evidence to improve

A beautiful workbook does not demonstrate improved learning. Observe the independent attempt and revise the unclear step.

**Your practice:** What goes on a minimal feedback record?

**Worked example / answer check:** Task, unaided success yes/no, misconception, permitted feedback and lesson revision.

**Transfer:** Try a new case from a different topic, without copying the example; write down what you checked.

## Independent challenge
Design a ten-minute lesson, try one independent transfer activity and change one instruction based on the learner's actual work.

Use this evidence card: **before / action / expected / observed / one limitation / next test**.

## Five-day practice
- Day 1: Try lesson one before reading its example answer.
- Day 2: Recall the core idea with notes closed; check and correct.
- Day 3: Try another lesson with a changed example.
- Day 4: Complete the independent challenge.
- Day 5: Show the result to a suitable reviewer and revise one step based on real feedback.
